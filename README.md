# Поиск вакансий
Это программа, которая получает данные о компаниях и вакансиях с сайта hh.ru и сохраняет их в БД. 
Пользователю предоставляется возможность просматривать полученную информацию в удобном формате в виде списков.

## Содержание
Для запуска - python main.py
Если данные уже загружены в БД, будет предложено обновить БД. 
Если же данные не были загружены, загрузка начнется автоматически. 
После пользователю выводится меню и предлагается выбрать нужный вариант просомтра информации.
